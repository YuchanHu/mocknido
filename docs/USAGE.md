# 使用说明

启动后，在顶部选择写真画册、定制抱枕或拍立得，上传设计图片并调整参数。

## 画册

封面比例自动跟随上传图片。用厚度和覆膜反光控制书本质感，用三轴滑块或拖动画面调整朝向。

## 抱枕

当前使用 `pillow_obj/pillow_squ.fbx` 底模。1:1 保留方形外观，2:3 与 1:2 在同一底模上调整横向尺寸。饱满度 0.9、褶皱强度 1 对应原网格厚度与细节。定制图片投射到正面，背面为素色布料。

## 拍立得

支持 Polaroid 600 / i-Type、富士 instax mini 和 WIDE。成像区与外框使用各自比例，相纸含白边、厚度与阴影；富士型号带药包压痕。

相纸规格来源见 THIRD_PARTY_NOTICES.md。成像区位置与压痕为参考正面样图的近似测量，不代表制造公差。

## 手动裁切

在图片适配中选择“手动选择裁切”，拖动取景框，用滑块或滚轮缩放，点击“应用裁切”。取景比例跟随抱枕比例或相纸成像区。更换图片、切换底模比例后需要重新取景。

## 输出与本地处理

导出透明 PNG，包含柔影。图片通过本机回环地址发送给本地进程处理，不发送到外部服务。上传文件在本次服务的临时目录中保存，正常退出时清理。会话状态不会永久保存。

浏览器下载位置由浏览器设置决定。命令行输出写入 `deliverables/` 或指定路径。请保留整个便携文件夹及底模，勿仅移动启动脚本。
